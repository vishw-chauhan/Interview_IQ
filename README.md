# InterviewIQ

**Prepare. Practice. Perform. Improve.**

InterviewIQ is an AI-powered interview preparation and assessment platform. Upload a resume, pick a target role, practice a personalized interview, and get feedback on every answer.

## Tech stack

- Frontend: React, Vite, React Router, Axios
- Backend: Node.js, Express
- Database: PostgreSQL

## Local setup

1. Create a PostgreSQL database named `interviewiq`.
2. Backend:
```
   cd backend
   copy .env.example .env
   npm install
   npm run migrate
   npm run dev
```
3. Frontend (new terminal):
```
   cd frontend
   npm install
   npm run dev
```
4. Open http://localhost:5173
